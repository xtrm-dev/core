# Research

Research is evidence acquisition, not a license to browse everything.

| Need | Read |
|---|---|
| Current library/SDK/CLI docs | `references/documentation.md` |
| Real public implementation examples | `references/code-search.md` |
| Exa semantic search, fetch, advanced retrieval, or multi-step research | `references/exa.md` |
| Recent ecosystem/community/news evidence | `references/recent-web.md` |
| Multi-source/academic investigation | `references/deep-research.md` |
| Verify a concrete claim | `references/fact-checking.md` |

Prefer primary/current sources for specifications and APIs. Community sources are useful
for operational experience and emerging practice, but separate them from authoritative
claims. Search ranking is candidate discovery, not validation: fetch and inspect important
sources, seek disconfirming evidence, and preserve unresolved contradictions.

Use specialized sources when they are stronger than general semantic search: local
GitNexus for the current repository, official/current documentation indexes for exact API
behavior, and public-code search for literal implementation evidence.

Do not copy third-party research skills wholesale into XTRM. Keep credentials and
provider-specific orchestration behind deliberate managed integrations, and never put
secrets or proprietary payloads into external research queries.
